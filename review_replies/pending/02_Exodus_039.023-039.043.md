Notes:
- Exodus 39:23 p19–p20: grouped "پاره نشود" as H3808 H7167 (negated passive verb in one phrase). The Hc of o1 is not rendered.
- Exodus 39:24: the Persian adds "کتان ریزبافت" (fine linen, as in LXX/SP), which the Masoretic text lacks here; left it untagged and did not borrow H8336 from another verse. The second "و" (before کتان) is untagged for the same reason.
- Exodus 39:25 p9 / 39:26 p8: "گِرد" tagged H5439 (סָבִיב); in 39:24 "گرد دامن" stays as one group for H7757, since there is no סָבִיב.
- Exodus 39:26 p17: "تن می‌کردند" ("wore") is added in translation; untagged. "یکی در میان" (alternately) renders the repeated pattern and is left untagged.
- Exodus 39:28: split "ریزبافتِ تابیده" and regrouped as "کتان ریزبافتِ" H8336 + "تابیده" H7806. H906 (הַבָּד, linen) is not separately rendered, so it is not tagged. "دوختند" has no verb behind it in this verse; untagged.
- Exodus 39:29 p6: kept "ماهرانه" as H4639 (מַעֲשֵׂה רֹקֵם), but this is uncertain.
- Exodus 39:30 p13 "به‌سان": untagged, since there is no Hk in the Hebrew. p12 "را" untagged (no אֵת before מִכְתַּב).
- Exodus 39:31: H4605 (מִלְמַעְלָה, "above") is not rendered. p9 "را" untagged (no אֵת).
- Exodus 39:32 p17 / 39:42: "را" after "همه چیز" has no אֵת in 39:32, so it is untagged. In 39:42 "این همه را" renders אֵת כָּל הָעֲבֹדָה; H5656 is not separately tagged (unsure whether "این" should carry it).
- Exodus 39:40 p28: "یعنی" kept as Hl (לְאֹהֶל rendered appositionally); this is uncertain.
- Exodus 39:43 p12: "درست" tagged H3651 (כֵּן), following 39:42; p20 "پس" changed to Hc only.
- No numbers were taken from neighbouring verses.
