Notes (uncertain cases; no numbers taken from neighbouring verses):
- Deuteronomy 14:1 p9 پس: no "and" stands before the first prohibition, so I removed Hc. p21 متراشید renders the whole of לא תשימו קרחה ("make no baldness"), so it gets H3808 H7760 H7144.
- Deuteronomy 14:2 p18–p19 شما را renders וּבְךָ (Hc + Hb + suffix). I left it untagged because Hb only marks the object of בחר. p23 که is not the Hebrew אשר, which has no Persian equivalent here ("روی زمین" follows directly), so I untagged it. p25 اوست probably renders לוֹ (Hl); I left it untagged.
- Deuteronomy 14:5: the animal identifications follow Hebrew word order (צבי=غزال, יחמור=گوزن, אקו=بز کوهی, דישן=بز وحشی, תאו=غزال وحشی, זמר=قوچ کوهی). The NMV's zoology is loose, so this mapping is by position.
- Deuteronomy 14:6 p11 بخش→H8157 and p12 شکافته باشد→H8156: these two may be the other way round (שֹׁסַעַת שֶׁסַע, "cleaving a cleft").
- Deuteronomy 14:7 p27–p28 / 14:8 p13–p14 "و از این رو": these are added in translation, so I untagged them. بر→Hl for לָכֶם. 14:7 حرامند gets H2931 H1992 for the copula הֵם.
- Deuteronomy 14:8 p23–p24 چنین حیواناتی renders the suffix ־ם and stays untagged. p25 را has no אֵת behind it, so I untagged it. p31 نیز is not a negation, so I removed H3808.
- Deuteronomy 14:9 p20 دارد→Hl and 14:10 ندارد→H369 Hl: the possession is expressed by לוֹ. This is debatable.
- Deuteronomy 14:12 p3 را: there is no אֵת, so I untagged it. אֲשֶׁר and מֵהֶם are not rendered.
