- Deuteronomy 7:1 p12 (به): left untagged; it renders the directional ending of שָׁמָּה, which has no number of its own.
- Deuteronomy 7:2 p21 (و): untagged because there is no vav before לֹא תִכְרֹת. p25 مبند tagged H3808 H3772, with the negative prefix and the verb "cut" (a covenant).
- Deuteronomy 7:3: the negatives are tagged on the prohibitive verbs (منما, مده, مگیر get H3808). The Hc of וְלֹא is not rendered.
- Deuteronomy 7:6 p10 (او): this stands in for יְהוָה אֱלֹהֶיךָ (o9-o10) but is left untagged, which is doubtful.
- Deuteronomy 7:7 p15 (دیگر): tagged H3605 because it loosely renders כָּל, which is doubtful. p8 نبست gets H3808 H2836.
- Deuteronomy 7:8 p12 (می‌خواست): left untagged as a translator's addition; "به جای آورد" is grouped as H8104.
- Deuteronomy 7:10: אֶל פָּנָיו (o3-o4, o9-o10) is not rendered, so the H6440 tag on p23 از was removed.
- Deuteronomy 7:11 p15-p16 (به‌دقّت / نگاه دارید): the H8104 and H6213 tags are left as they were. Unsure how the Persian splits וְשָׁמַרְתָּ … לַעֲשׂוֹתָם.
- Deuteronomy 7:12 p2 (اگر → H6118): kept, though עֵקֶב is idiomatic here.
- No numbers were taken from neighbouring verses.
