Notes (unsure cases; no numbers were taken from neighbouring verses):

- Exodus 29:24 p3 (را → H853): left as is, but this را marks the object of "put" (הַכֹּל has no אֵת); the אֹתָם belongs to "wave", whose object the Persian leaves implicit.
- Exodus 29:25 p23–p24 (این است): kept H1931 on است as elsewhere; this could arguably go on این instead.
- Exodus 29:27: p1 قسمتهایی untagged (no original word; was H8641). The Persian has only "تکان داده می‌شود" for both הוּנַף and הוּרָם, so it is grouped as H5130 and H7311 is left out (was wrongly "H7311 H175").
- Exodus 29:29 "از آنِ" grouped as Hl (לְבָנָיו); p18–p19 grouped "منصوب شوند" as H4390 H3027.
- Exodus 29:30: "برگزیده می‌شود" has no Hebrew word behind it (so می‌شود is no longer H935); می‌گردد tagged H935 together with وارد (a compound verb split by its object).
- Exodus 29:33: "از این چیزها" probably renders אֹתָם (H853), but it is left untagged; است tagged H1992 (הֵם) following the H1931 convention.
- Exodus 29:34 p11 (چیزی → H4480): kept because it expresses the partitive "some of", but this is doubtful. "همه را" for אֶת הַנּוֹתָר: همه is left untagged (it could be H3498).
- Exodus 29:35: هر → H3605 and چه → H834 (Hk is not rendered); دربارۀ → Hl.
- Exodus 29:36: "هر روز" grouped as H3117 to match 29:38 (Hl of לַיּוֹם is not rendered separately); برای → H5921, read as עָלָיו/עַל.
- Exodus 29:39/29:41: "به هنگام" grouped as H996 (בֵּין).
- Exodus 29:40: "تقدیم کن" has no verb behind it in the Hebrew, so it stays untagged.
- Exodus 29:42: با → Hl (לָכֶם); "نسل اندر نسل" grouped as Hl H1755.
- Exodus 29:46: هستم untagged in both places (it is a copula, and אֲנִי is already tagged on من).
