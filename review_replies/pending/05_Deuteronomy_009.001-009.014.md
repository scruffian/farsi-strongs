Notes:
- Deuteronomy 9:1 p15 (سرزمین): untagged as an addition; the Hebrew has "to dispossess nations", no word for land. p37 (را): untagged, since the only אֵת in the verse is before the Jordan. p32 (کشیده) is left as H1219, but it is really part of the idiom "سر به فلک کشیده" for בַּשָּׁמַיִם, so it is uncertain.
- Deuteronomy 9:2 p5–6: joined into "بلند قامتند" (H7311). Before the change, قامتند was wrongly tagged H1121. بنی‌عَناق and عَناقیان now also carry H1121 for בְּנֵי.
- Deuteronomy 9:3 p13 (پیشاپیش): changed to "Hl H6440" because it renders all of לְפָנֶיךָ.
- Deuteronomy 9:4: Hl from מִלְּפָנֶיךָ is moved from شما to حضور. p2 (چون) now gets Hb for בַּהֲדֹף. "حال آنکه" is grouped as Hc. Hd is dropped from both این entries (rule 6). The را entries after pronoun suffixes are untagged (no אֵת).
- Deuteronomy 9:4–6: in "به سبب", only به is tagged Hb and سبب stays untagged. This choice is uncertain.
- Deuteronomy 9:5 p10 (شما): left as H859. The word reads more like the suffix of לבבך, so this is uncertain.
- Deuteronomy 9:7 p30 (پیوسته): changed to H1961, because it renders the continuous "ye have been" (הֱיִיתֶם) with the participle. This is uncertain.
- Deuteronomy 9:8 p9 (او): tagged H3068 because it renders the second יהוה. p14 (که): tagged Hl for לְהַשְׁמִיד, which is uncertain.
- Deuteronomy 9:14 p15–16 (از تو): left untagged. They might render אוֹתְךָ (H853), so this is uncertain.
- No numbers were taken from neighbouring verses.
