- Leviticus 13:10 p11–p12: «است» there is existential, so I left it untagged. I tagged «که» Hc H1931 for וְהִיא («which has turned»). Not fully sure.

- Leviticus 13:14 p2 «اگر» → H3117 kept for וּבְיוֹם («when»). Untagged «بدن» because it only expands בּוֹ.
- Leviticus 13:16 p7–p8: grouped «بار دیگر» with H2015 (וְנֶהְפַּךְ «turn again»). «شود» also has H2015. Not sure.
