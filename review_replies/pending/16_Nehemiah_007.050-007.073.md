- Nehemiah 7:61 p20 (که → H518): treated که as rendering אִם "whether"; moderately confident.
- Nehemiah 7:64: joined "نسب‌نامه‌ها ثبت" + "شده بودند" → H3187 (H4672 belonged to نیافتند); joined "از این رو" → Hc (וַ of o7); "محروم شدند" → H1351, kept نداشتن → H1351 and untagged لازم. The rendering of גָּאַל is paraphrastic; unsure which words best carry it.
- Nehemiah 7:65 p8 دارای → Hl (לְאוּרִים); p15 خوراک kept H398 though it is arguably an added noun.
- Nehemiah 7:68: the Hebrew text given for this verse is the camels/asses line (same as 7:69; the horses/mules line is missing in this Hebrew edition). The Persian (horses and mules) has no matching original words, so I removed all tags.
- Nehemiah 7:66, 7:67 p10, and similar: "تن" is added in translation, so I untagged it; the full number tags now sit on the numeral.
- Nehemiah 7:69 p3 و: untagged because there is no וְ before חֲמֹרִים (the Hc belongs to the numbers).
