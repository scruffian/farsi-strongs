- Exodus 6:25 p4 (یکی): removed H3947 (it is "one of", no original word). p8 (را): removed H853, since there is no אֵת before בְּנוֹת. p13–15: grouped "صاحب پسری شد" as rendering וַתֵּלֶד לוֹ (H3205); unsure whether the Hc should go on و (kept on و). p22 (خاندانهای): changed from H1 H4940 to H1 only; H4940 is rendered by طایفه‌ای.

- Exodus 6:26 p10 (بدیشان): tagged Hl for לָהֶם. p21–22: grouped "بیرون برید" (H3318). Unsure: p1 آری might loosely render the emphatic הוּא, so left untagged.
- Exodus 6:27 p6 (بودند → H1992): kept, but it is doubtful; הֵם is rendered only loosely by the plural copula.
- Exodus 6:29 p10 (هرآنچه): H3605 H834. p11 (به): tagged H413 for אֵלֶיךָ. p12 (تو): untagged because it renders a pronoun suffix and is not אֲנִי. p19 (بازگو): tagged H1696 for the imperative דַּבֵּר.
