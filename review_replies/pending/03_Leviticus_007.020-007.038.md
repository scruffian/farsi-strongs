- Leviticus 7:36: the first که was untagged because Persian reordered the verse and אֲשֶׁר is not clearly rendered (unsure). The object را (p13) was untagged because there is no אֵת for it. بدیشان → Hl (לָהֶם).
- Leviticus 7:37: the Persian has no final period. It was left as is.
